# 1 引言（中文初稿）

六自由度（6D）目标位姿估计旨在从视觉观测中恢复刚性目标相对于相机的三维平移与三维旋转，是机器人操作、增强现实、自主导航与场景理解中的基础问题。近年来，以 LINEMOD、YCB-Video、T-LESS 及 BOP 系列为代表的数据集推动了基于对应关系、模板匹配、渲染优化和深度网络的快速发展。特别是 BOP 通过统一数据格式、对称性感知指标和在线评测，建立了较为标准的物体位姿估计评价体系。然而，现有基准主要围绕室内桌面物体、工业零件或手持物体构建：目标通常处于近距离成像条件，在图像中占据较大区域，运动速度有限，场景范围和背景类型也相对受控。T-LESS 等数据集重点研究无纹理、相似外形和遮挡问题，YCB-Video 强调室内杂乱场景，而现有跟踪数据集则多采用实验室环境中的预设轨迹。这些基准对于机器人操作十分重要，但尚未充分覆盖复杂室外环境中的远距离飞行器目标。

这种数据分布上的局限进一步影响了现有算法的设计假设。首先，大量方法依赖清晰且尺度充足的目标外观、稳定的检测或分割结果，以及连续帧之间较小的位姿变化；当目标仅占据少量像素或存在严重运动模糊时，局部特征、轮廓和稠密对应关系都会显著退化。其次，现有方法通常在单帧内产生唯一位姿，或使用简单的恒速模型进行时序传播，难以处理飞行器近似对称结构引起的航向歧义，以及高速滚转、俯仰和转弯造成的大角度旋转。最后，许多跟踪方法将遮挡、分割误差和位姿残差直接反馈至模型更新，容易在长序列中累积漂移。由于现有测试集较少同时包含远距离小目标、高角速度、复杂室外背景、强光照变化、长时间遮挡和目标重现，上述失效在常用平均指标中往往无法被充分揭示。

飞行器目标的 6D 位姿估计具有明确的应用价值。与仅给出二维边界框或三维中心位置的检测任务不同，6D 位姿同时描述目标的位置、滚转、俯仰与航向，可为飞行状态理解、空域监测、碰撞预警、编队协作、自主对接与回收、飞行测试和异常姿态分析提供更完整的空间状态。尤其是在目标没有主动发送导航信息或无法依赖合作标志时，基于视觉的非合作式姿态测量具有重要意义。然而，飞行器具有机翼、旋翼和尾翼等细长结构，在远距离成像中容易发生结构消失；其近似对称外形又可能产生多个视觉上相似但运动意义不同的旋转解。与此同时，高速运动、剧烈尺度变化、天空与地面背景切换以及出视野后的重新出现，使飞行器位姿估计与跟踪形成了区别于传统桌面物体的独立研究问题。

在此基础上，本文提出 **[METHOD_NAME]**，一种面向飞行器目标的结构—动力学感知 6D 位姿估计与跟踪框架。该方法首先通过多尺度时序特征聚合增强远距离小目标的结构表征，并显式利用机头、翼尖、尾翼和旋翼中心等飞行器结构线索约束旋转估计；随后，以对称性感知的多假设表示保留单帧中不可消除的姿态歧义，并利用跨帧运动一致性逐步完成假设选择；最后，方法联合估计位姿与不确定性，根据目标可见度、图像模糊程度、运动创新量和时序一致性，在正常跟踪、状态传播与重新定位之间进行风险感知切换。该设计避免将低质量观测直接写入目标模型，并将优化目标从单帧轮廓拟合转向长序列最终位姿风险。

## 写作与实验占位说明（投稿前删除）

- 在完成系统文献检索前，不要无条件使用“首个”；应限定传感器、任务、目标类别和数据规模。
- `[N_OBJECTS]`、`[N_SEQUENCES]` 和 `[N_FRAMES]` 必须填写最终公开版本的实际数量。
- 若没有真实数据，应将“仿真到真实”写成局限性，不能宣称真实泛化；最好补充一个小型真实测试集。
- 必须明确测试阶段是否提供 CAD、真实尺度、初始位姿和目标检测框，这决定任务属于 model-based、novel-object 还是 category-level。
- Introduction 中的方法描述需要随最终架构更新；当前文本是研究路线，而不是对尚未实现模块的完成性声明。
- “现有算法受到数据集限制”的表述应通过跨数据集实验支持，避免将相关性写成未经验证的因果关系。
